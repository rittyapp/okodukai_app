# おこづかい帳（okodukai_app）

子供が「お手伝いボタン」を押し、親が承認すると残高が増える、家族向けのおこづかい帳アプリです。
画面は GitHub Pages、データは **各家庭の Google スプレッドシート**（＋Apps Script）に保存されるので、無料で使えます。

- アプリ：https://rittyapp.github.io/okodukai_app/
- お試し（データは保存されません）：https://rittyapp.github.io/okodukai_app/?demo=1
- 仕様書：[docs/SPEC.md](docs/SPEC.md)

```
[スマホ/PC] ── GitHub Pages（index.html / app.js）
      │ fetch
      ▼
[各家庭の Apps Script（gas/Code.gs）] ──▶ [各家庭のスプレッドシート]
```

---

## 使い方

### A. 家族が使い始める（2人目以降・子供）

1. 親の端末でログイン画面の「共有QRコード」を開き、家族の端末で読み取る
2. 開いたページをホーム画面に追加する（iPhone：共有 →「ホーム画面に追加」／Android：メニュー →「ホーム画面に追加」）
3. 子供は親から教えてもらった4桁のPINで、親は「Googleでログイン」でログインする

### B. 新しい家庭で最初に準備する（親が1回だけ）

1. アプリを開くと「はじめかた」画面が出る
2. **原本をコピーする**を押し、自分のGoogleドライブにスプレッドシートをコピーする
   （原本が未公開の場合：空のスプレッドシートを作り、「拡張機能 → Apps Script」に `gas/Code.gs` と `gas/appsscript.json` の内容を貼り付ける。`appsscript.json` はエディタの「プロジェクトの設定」→「"appsscript.json" マニフェスト ファイルをエディタで表示する」をオンにすると編集できる）
3. コピーしたスプレッドシートで「拡張機能 → Apps Script」を開き、**デプロイ → 新しいデプロイ**
   - 種類：ウェブアプリ／次のユーザーとして実行：**自分**／アクセスできるユーザー：**全員**
   - 「アクセスを承認」で自分のアカウントを選び、表示される権限をすべて許可する
     （「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」。自分で作ったスクリプトなので問題ありません）
4. 表示された **`/exec` で終わるURL** をコピーし、アプリの「はじめかた」画面に貼り付けて **接続する**
5. ログイン画面の **「初期設定」** を押し、**スプレッドシートの持ち主のGoogleアカウント**でログインする
   → シートが自動で作られ、その人が最初の親として登録される
6. 完了画面の案内に従って、**設定タブでアプリ名とアイコンをデザイン**し、**ユーザータブで子供（4桁PIN）を登録**する
7. A の手順で家族に配る

> スプレッドシートのメニュー「おこづかい帳 → アプリのURLを表示」でも、家族に配るURLを確認できます。

### C. このリポジトリの管理者がやること（1回だけ）

| やること | 理由 |
|---|---|
| Google Cloud の OAuth クライアント（ウェブアプリケーション）に **承認済みのリダイレクト URI** `https://rittyapp.github.io/okodukai_app/` を追加 | GitHub Pages からの「Googleでログイン」に必要 |
| OAuth 同意画面を **「本番環境」** に公開（スコープは openid / email / profile のみ） | テスト中のままだと、テストユーザーに追加した人しかGoogleログインできない |
| GitHub の Settings → Pages で `main` ブランチの `/ (root)` を公開 | アプリの配信 |
| 原本スプレッドシートを作り「リンクを知っている全員：閲覧者」で共有、そのIDを `config.js` の `TEMPLATE_SPREADSHEET_ID` に書く | 「原本をコピーする」ボタンを使えるようにする（個人データを入れないこと） |
| `icons/` のアイコンをデザインして差し替える | 標準アイコン（各家庭は設定タブで自分用アイコンも作れる） |

### スクリプトプロパティ（任意）

コードを書き換えずに、Apps Script の「プロジェクトの設定 → スクリプト プロパティ」で変更できます。

| プロパティ | 内容 |
|---|---|
| `OAUTH_CLIENT_ID` | 自分で用意したOAuthクライアントIDを使う場合に設定（未設定なら共通のIDを使う） |
| `OAUTH_CLIENT_SECRET` | **v3では不要**（IDトークン方式のためシークレットを使わない）。残っていても無視される |
| `FRONTEND_URL` | 画面を自分のフォーク先で公開した場合、そのURL |

## 更新とロールバック（前のバージョンに戻す）

### 更新するとき

1. `config.js` の `VERSION` と `gas/Code.gs` の `SERVER_VERSION` を上げる
2. GitHub に push し、`vX.Y.Z` のタグを付ける（GitHub Pages は1〜2分で反映）
3. 各家庭の Apps Script：`gas/Code.gs` を貼り付けて保存 → **デプロイ → デプロイを管理 → 鉛筆（編集）→ バージョン「新バージョン」→ デプロイ**
   （「新しいデプロイ」ではなく既存のデプロイを編集すると、`/exec` のURLが変わらない）

### 戻すとき

| 対象 | 戻し方 |
|---|---|
| Apps Script | **デプロイ → デプロイを管理 → 鉛筆 → バージョンで以前の番号を選ぶ → デプロイ**。URLは変わらない。コードも戻す場合は、エディタ左の「プロジェクト履歴」（時計アイコン）から以前の版を開いて内容をコピーする |
| 画面（GitHub Pages） | GitHub で戻したいコミットを `Revert` する、またはタグの版のファイルで上書きして push する。家族のブラウザには自動で反映される（反映されない時は再読み込み） |
| スプレッドシートのデータ | 「ファイル → 変更履歴 → 変更履歴を表示」から戻したい時点を選び「この版を復元」 |
| シートが壊れた | 親の「設定」タブ → **初期設定（シートの修復）**。足りないシート・列を作り直すだけで、データは消さない |

> v2（Apps Script内の画面）へ戻す場合は、Apps Script のデプロイで v2 時点のバージョン番号を選べば、元のURLでv2画面に戻ります。
> v3 で追加された Ledger の `RequestedById` 列は v2 では単に無視されます。

## ファイル構成

| パス | 内容 |
|---|---|
| `index.html` / `style.css` / `app.js` | 画面（GitHub Pages） |
| `config.js` | 公開してよい設定（バージョン・共通クライアントID・原本ID） |
| `manifest.json` / `icons/` | ホーム画面追加用の情報とアイコン |
| `demo/mock.js` | `?demo=1` 用。Code.gs をブラウザ内で動かすお試しモード |
| `gas/Code.gs` / `gas/appsscript.json` | 各家庭の Apps Script に貼るサーバー側コード（変数の説明はファイル冒頭） |
| `docs/SPEC.md` | 仕様書（他のAIでも同じものが作れるように書いたもの）と QA |

## 秘密情報について

- このリポジトリには、個人のメールアドレス・スプレッドシートID・デプロイURL・クライアントシークレットは入っていません。
- OAuth クライアントIDはブラウザに渡る公開前提の値です（リダイレクト先が GitHub Pages に固定されているため、他サイトでは使えません）。
- 子供のPINはアプリ上に表示されません。紙や口頭で伝えてください。
