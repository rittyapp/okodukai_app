🐷パパ貯金 はじめかた

このアプリは、あなたのGoogleスプレッドシートにデータを保存します。最初に親が1回だけ準備します（無料）。

  1. 原本スプレッドシートをコピー
  2. ウェブアプリとして公開
    コピーしたスプレッドシートで「拡張機能」→「Apps Script」→「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、 実行ユーザー「自分」、アクセス「全員」でデプロイし、表示される許可をすべて承認します。 /exec で終わるURLをコピーします。
  3. URLを貼り付けて接続
  4. 接続できたら、ログイン画面の「初期設定」を押し、スプレッドシートの持ち主のGoogleアカウントでログインします。
    ※ 現在「Googleでログイン」はテスト公開中です。使う前に、管理者へGmailアドレスを伝えて登録してもらってください（README参照）。

家族から共有QRコードを受け取った人は、それを読み取るだけで使えます。

ボーナス
定期おこづかい
支給日を過ぎると子供の画面に「おこづかい発生中」が出て、押すと1か月分ずつ受け取れます（その月の支給日の日付で記録）。
りそく（使わずにためると、毎月ふえる）
毎月、月末の残高 × % を切りすてで計算し、子供の画面で「うけとる」を押すと翌月1日付で入ります。受け取っていない月のりそくにも次の月のりそくが付きます（ふくり）。オンにした月から付き始めます（さかのぼりません）。りそくは本物のお金なので、払える範囲の%にしてください。
りれきの表示件数
子供の画面のりれきは、最新のこの件数だけ表示します。それより前はカレンダーの日付から見られます。
PINをまちがえた端末
ロック中でも子供の画面には「ちがいます」としか出ません。1度でもPINを間違えた端末を表示します（「非表示」にしても、また間違えると表示されます）。
心当たりのない失敗はありませんか？
配ったばかりのころは、子供のいたずらや押しまちがいでもここに出ます。
使い始めてしばらくたってから心当たりのない失敗が出たときは、アプリのURL（共有QRコード）が家族以外にもれて、だれかがPINを試している可能性があります。
その場合は、Apps Script で新しいデプロイを作ってURLを変え、古いデプロイを「アーカイブ」してから、新しい共有QRコードを家族に配り直してください（手順は README の「URLがもれたかもしれないとき」）。
